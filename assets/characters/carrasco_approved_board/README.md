# Carrasco aprovado — fonte da apresentação jogável

`approved_concept.png` é a arte **Evolução III — Carrasco do Bosque** indicada pelo usuário. `approved_animation_board.png` é o quadro de poses aprovado na mesma instrução.

`sheet.png` contém recortes das poses desse quadro, com o fundo escuro removido, redimensionados para apresentação no jogo. `frames.json` registra as poses e os pivôs. O quadro original e a concept art ficam preservados aqui para revisão. Os recortes permitem testar a forma aprovada no trecho jogável; não constituem uma animação redesenhada pixel a pixel.
